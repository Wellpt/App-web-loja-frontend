# Marca VTcell

Arquivos raster recriados a partir da imagem de referência fornecida pelo responsável. Não são os arquivos vetoriais originais.

- `vtcell-logo-light.png`: marca verde para superfícies claras, com transparência.
- `vtcell-logo-dark.png`: marca branca e verde sobre fundo verde escuro.
- `vtcell-logo-print.png`: versão preta sobre fundo branco para documentos.
- `vtcell-app-icon.png`: símbolo VT com telefone sobre fundo verde; matriz para ícone da aplicação e favicon.

Não incluem legendas ou controles da imagem de apresentação. Integrados ao login, menu lateral, cabeçalho, favicon e impressões de orçamentos e ordens de serviço. Os caminhos respeitam a base da aplicação no GitHub Pages. A impressão aguarda o carregamento da imagem.

O favicon utiliza o PNG da aplicação, dimensionado pelo navegador. Exportações específicas em 16/32/512 pixels não foram realizadas. Não ampliar os arquivos além da resolução original.
